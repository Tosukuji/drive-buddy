# キャラボイスの作り方(VOICEVOX)

ドライブ相棒の5人のセリフを、VOICEVOX(無料の音声合成ソフト)の声で作るための一式です。
声はあなたのPCで作り、できたファイルを送ってもらえれば、アプリに組み込みます。

## 用意するもの
- PC(Windows または Mac)
- VOICEVOX(無料):https://voicevox.hiroshiba.jp/ からダウンロードしてインストール

## 手順
1. **VOICEVOX を起動**しておく(起動している間、PCの中で声を作る仕組みが動きます)
2. **声を選ぶ**:`voices.txt` をメモ帳などで開き、キャラごとの番号を決める(下の表を参照)。
   VOICEVOX のキャラクター一覧で試し聞きしてから決めるのがおすすめです。
3. **声を作る**
   - Windows:`make_voices.bat` をダブルクリック
   - Mac:`make_voices.command` を右クリック →「開く」(開けないときはターミナルで `bash make_voices.command`)
   - 5人分(約1,300本)で、PCの性能により10〜40分ほどかかります。途中で止めても、もう一度実行すれば続きから作ります。
4. **送る**:できた `out` フォルダを ZIP にして、チャットに添付してください。

## 規約について(必ず確認)
- VOICEVOX の音声は、声ごとに利用規約があります。多くは「VOICEVOX:キャラ名」のクレジット表記で商用・非商用OKですが、
  **自作キャラ(ミチなど)の声として使ってよいか**、アプリに入れて有料・広告ありで配布してよいかは、各キャラの公式規約で確認してください。
- 次の声は条件が厳しいため、今回は候補から外しています:もち子さん(ゲーム作品等は不可)、No.7・ユーレイちゃん(商用は事前確認)、
  ぞん子(商用は問い合わせ)、青山龍星・後鬼(企業が関わる場合は事前確認)、Voidoll(法人は問い合わせ)。
- アプリには「キャラボイス:ミチ: VOICEVOX:四国めたん」のようにクレジットを表示します。

## ファイルの説明
| ファイル | 中身 |
|---|---|
| `<キャラ>.txt` | 声にするセリフ(1行=1本)。おみやげ名などは単独の行になっています |
| `<キャラ>.json` | 行番号と文章の対応(アプリへの取り込みに使います) |
| `voices.txt` | キャラごとの声の番号 |
| `make_voices.bat` / `make_voices.ps1` | Windows 用の作成スクリプト |
| `make_voices.command` | Mac 用の作成スクリプト |

## 取り込み(開発者向け)
```
cd dev
node voice_import.mjs sora <out/sora のフォルダ> --credit "VOICEVOX:白上虎太郎"
node build.mjs
```
`docs/voice/<キャラ>/` に変換済みの音声(AAC)と一覧が置かれ、アプリはその声で話します。録音がないセリフは端末の声で話します。
